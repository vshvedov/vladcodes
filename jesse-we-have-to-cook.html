Jesse, We Have to Cook

A macOS utility to prevent system sleep and to keep active status in messaging apps.

Keep your Mac awake and stay active while compiling, streaming or thinking. Jesse, We Have to Cook is a free, lightweight menu bar utility for macOS that prevents your computer from going to sleep, blocks the screensaver, and ensures you remain active in work communication platforms.

Installation

To install "Jesse, We Have to Cook", download the latest release from the link above and unzip the file. Drag the application to your Applications folder and launch it.

As this is a self-signed app distributed outside of the Mac App Store, you may need to right-click the app and select "Open" the first time you run it to bypass macOS security warnings. Or go to System Preferences > Security & Privacy > General and click "Open Anyway" for the app.

Alternatively, you can compile the app from source if you have Xcode installed. Clone the repository, open the Xcode project, and build & run the app on your machine.

Key features

  • Prevent Mac sleep mode: keep your macOS computer awake and active without manual intervention.
  • Stay active in messaging apps: maintain online presence in communication platforms.
  • Lightweight and efficient: minimal RAM and CPU footprint (under 10 MB memory usage).
  • Menu bar integration: easy access and control directly from your macOS menu bar.
  • Open source software: fully transparent, auditable codebase available on GitHub.
  • Completely free: no cost, no subscriptions, no premium features, no ads.
  • Privacy focused: no data collection, no analytics, no network requests.
  • macOS native: built specifically for Mac with native macOS APIs.

System requirements

  • Operating system: macOS 10.14 (Mojave) or later.
  • Architecture: Apple Silicon and Intel Macs supported.
  • Memory: ~30 MB RAM usage.
  • Storage: under 4 MB disk space.
