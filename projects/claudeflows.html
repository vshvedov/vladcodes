claudeflows

A composable agent workflow toolkit for Claude.

Claudeflows is a composable agent workflow toolkit for Claude. It bundles a set of slash-command skills (cf-feature, cf-bug, cf-precommit-review, and friends) that turn ad-hoc prompting into a repeatable design, build, review loop. Open source under the OmniPrag organization.
